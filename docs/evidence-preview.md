# Evidence preview

Run `npm ci`, then `npm run dev` and open `/evidence`.
Use the scenario links to inspect risk, opportunity, and missing-debt examples.
Input links resolve to exact local example values. Amounts remain decimal strings.
Results use the existing method v0.1 company calculation.

This is the presentation slice of issue #5. Examples are explicitly synthetic;
they are not persisted observations, datasets, or signal runs. Public comparison
is explicitly not comparable because no reviewed indicator mapping is attached.

Completion of #5 still requires a persisted evidence read contract, source
snapshot resolution, and integration with pinned dataset/signal identifiers.
The page-local examples do not establish a public API or database schema.
